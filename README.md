# JabVolley

**Play Hard, Play Together** - a responsive 4-page website about volleyball (Home, About Volleyball, Schedule, Contact).

- **Course:** INTROWEB WD202, Holy Angel University
- **Developer:** Joshua Jabez P. Sagad (BSIT 2nd Year)
- **Live site:** https://joshuajabez07-oss.github.io/jabvolley/

## Tech
HTML5 semantic tags, CSS3 (Flexbox, Grid, custom properties, media queries), vanilla JavaScript.

## Structure
```
index.html  about.html  schedule.html  contact.html
assets/css/styles.css      styles (BEM naming; desktop > 1024px, tablet <= 1024px, mobile <= 600px)
assets/js/script.js        hamburger menu, video pop-up, form validation
assets/images/             photos, logo, social icons
assets/video/              lesson video
```

## Run locally
Open `index.html` in a browser. No build step needed.
